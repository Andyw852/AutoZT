| A. Prescreening | `te-screen` | screen | Surrogate n/p electronic ZT<sub>e</sub> and power-factor scores (no κ<sub>L</sub>) | ML (ridge) | NumPy | Local | 2D only |
| B. Structure and stability | `opt-dft-cpu` | input | Relaxed structure; total, formation and intercalation energies | DFT | VASP, VASPKIT | CPU | ✓ |
|  | `opt-mlff-cpu` / `opt-mlff-gpu` | input | Relaxed structure and formation energy (high-throughput prescreen) | MLIP | MACE, ASE | CPU / GPU | ✓ |
|  | `phonon-dft-cpu` | check | Harmonic phonon dispersion with LO–TO correction; imaginary-mode and ZA stability gate | DFT + DFPT | VASP, VASPKIT, Phonopy, SeeK-path | CPU | ✓ |
|  | `phonon-mlff-cpu` / `phonon-mlff-gpu` | check | Harmonic phonon dispersion; imaginary-mode stability screen | MLIP | MACE, ASE, hiPhive, Phonopy (symfc) | CPU / GPU | ✓ |
|  | `elastic-dft-cpu` | check | Elastic tensor, Born stability, moduli; Debye temperature, sound velocities and minimum κ<sub>L</sub> estimate (3D) | DFT | VASP, VASPKIT, pymatgen | CPU | ✓ |
| C. Electronic structure, carriers and transport | `band-dft-cpu` | — | Semilocal and hybrid band structures and gaps; SOC for heavy elements; vacuum-aligned band edges in 2D | DFT | VASP, VASPKIT, SeeK-path | CPU | ✓ |
|  | `unihamgnn` | — | ML-predicted Hamiltonian, band structure and gap | ML | Uni-HamGNN, OpenMX tools | CPU | — |
|  | `ke-dft-cpu` | S, σ, κ<sub>e</sub> | S, σ, κ<sub>e</sub> and mobility (n, T) with ADP, IMP and POP scattering | DFT + DFPT | VASP, VASPKIT, AMSET, BoltzTraP2 | CPU | ✓ |
|  | `defect-dft-cpu` | — | Intrinsic defect formation energies, transition levels, self-consistent E<sub>F</sub>, n/p type | DFT | VASP, pymatgen, spglib | CPU | 3D |
|  | `eph-qe-cpu` | — | Wannier-interpolated electron–phonon matrix elements | DFT + DFPT | Quantum ESPRESSO, Wannier90, Perturbo | CPU | 3D |
| D. Lattice transport | `kl-dft-cpu` | κ<sub>L</sub> | fc2/fc3, LO–TO correction, κ<sub>L</sub>(T) | DFT + DFPT | VASP, VASPKIT, hiPhive, Phono3py (symfc / ALM); optional Pheasy, ShengBTE | CPU (GPU for Pheasy) | ✓ |
|  | `kl-mlff-cpu` / `kl-mlff-gpu` | κ<sub>L</sub> | fc2/fc3, κ<sub>L</sub>(T) | MLIP | MACE, ASE, hiPhive, Phono3py (symfc); optional Pheasy, ShengBTE | CPU / GPU | ✓ |
|  | `fit-fc-thermal` | κ<sub>L</sub> | Refit fc2/fc3 from existing displacement–force data, κ<sub>L</sub>(T), fitting-method sweep | Fitting | Pheasy, Phono3py (symfc / ALM), hiPhive; optional ShengBTE | CPU / GPU | ✓ |
| E. zT assembly | `zt-dft-cpu` | zT | S, σ, κ<sub>e</sub>, κ<sub>L</sub> → zT(n, T), peak zT | DFT + DFPT | VASP, VASPKIT, AMSET, hiPhive, Phono3py | CPU | ✓ |
| F. MLIP training | `mlff` | input | Material-specific fine-tuned MACE potential with phonon and EOS acceptance tests | DFT + MLIP | VASP, VASPKIT, MACE, hiPhive, Phonopy, ASE | CPU / GPU | ✓† |
| G. Bonding analysis | `cohp-cogito` | — | COHP, ICOHP and ICOBI bonding analysis | Post-proc. | COGITO (reads VASP WAVECAR) | CPU | — |

*Notes:* The 20 core skills occupy 17 rows; CPU and GPU variants share a row. zT role: S, σ, κ<sub>e</sub> / κ<sub>L</sub> / zT, the quantity of zT = S²σT/(κ<sub>e</sub> + κ<sub>L</sub>) the skill computes; input, a structure or potential that later stages use; check, a stability check; screen, a ranking before DFT; —, not part of the zT chain. Level: DFT, density-functional theory; DFPT, density-functional perturbation theory (VASP: dielectric tensor and Born charges; Quantum ESPRESSO: phonons and electron–phonon coupling); MLIP, machine-learning interatomic potential (MACE; the foundation model MACE-matpes-pbe-omat-ft by default, or a model fine-tuned by `mlff`); ML, other machine-learning models. Hardware: Local, login node or workstation without a batch queue. GPU variants evaluate MACE forces on the GPU; force-constant fits and Boltzmann solutions run on CPU, except Pheasy fits, which need a GPU. 2D: ✓, the skill detects a 2D slab and switches templates, relaxation constraints, units or thickness normalisation; †, implemented but not yet run on a 2D material; 2D only, trained on 2D materials only; 3D, the input is treated as bulk; —, not dimension-specific. `eph-qe-cpu` has so far been run only with smoke-test settings on Si. ADP, IMP, POP, acoustic-deformation-potential, ionised-impurity and polar-optical-phonon scattering; SOC, spin–orbit coupling; EOS, equation of state. Five further skills are listed in Supplementary Table S1.

## Table 2 | Coverage of the thermoelectric figure of merit zT = S²σT/(κ<sub>e</sub> + κ<sub>L</sub>).

| Quantity | DFT route | MLIP / MD route | Cross-check | Combined in |
|:--|:--|:--|:--|:--|
| S, σ | `ke-dft-cpu`: AMSET with ADP, IMP and POP scattering | — | BoltzTraP2 with deformation-potential τ (`ke-dft-cpu`) | `zt-dft-cpu` |
| κ<sub>e</sub> | `ke-dft-cpu`: AMSET | — | Lorenz number, AMSET vs BoltzTraP2 (`ke-dft-cpu`) | `zt-dft-cpu` |
| κ<sub>L</sub> | `kl-dft-cpu`: fc2/fc3 + Phono3py BTE | `kl-mlff-cpu` / `kl-mlff-gpu` (MACE); `kl-gpumd-3090` (NEP, HNEMD; Table S1) | `fit-fc-thermal` refits and method sweep; `phonon-lifetime` Ioffe–Regel check (Table S1) | `zt-dft-cpu` (reads `kl-dft-cpu` or `kl-mlff-*` only) |
| zT(n, T) | `zt-dft-cpu`; `ke-dft-cpu` reports zT(n) at 300 K when κ<sub>L</sub> is available | `zt-dft-cpu` with κ<sub>L</sub> from `kl-mlff-*` | AMSET vs BoltzTraP2 zT at 300 K (`ke-dft-cpu`) | — |

*Notes:* `kl-mlff-*` stands for `kl-mlff-cpu` and `kl-mlff-gpu`. Inside the chain, the imaginary-mode and ZA gate of `kl-dft-cpu` blocks the κ<sub>L</sub> step, and the DFPT dielectric tensor, elastic constants and deformation potentials that AMSET needs are computed within `ke-dft-cpu`; `phonon-dft-cpu` and `phonon-mlff-*` can be run beforehand as a stability screen. `zt-dft-cpu` reuses the electronic steps of `ke-dft-cpu` and the lattice steps of `kl-dft-cpu` and adds one summary step; when its own κ<sub>L</sub> is missing it reads the `kl-dft-cpu` or `kl-mlff-*` result of the same material (a 300 K-only `kl-mlff-*` result restricts zT to 300 K). κ<sub>L</sub> from `kl-gpumd-3090` or `fit-fc-thermal` is not read automatically. n is the nominal doping grid of AMSET; by default (`KTEMP_MODE` = interp) zT is reported only inside the κ<sub>L</sub> temperature window, and κ<sub>e</sub> includes the bipolar term. `te-screen` ranks candidates before this chain from electronic ZT<sub>e</sub> and power factor only. BTE, Boltzmann transport equation; HNEMD, homogeneous non-equilibrium molecular dynamics.

## Supplementary Table S3 | 2D-specific treatments along the workflow.

| Treatment | What it guards against | Where |
|:--|:--|:--|
| Dimension detection: vacuum ≥ 8 Å along exactly one axis → 2D; the decision is passed to later steps | Treating a slab as bulk | `skill/_common/opt/dim_common.py` |
| The 2D vacuum axis must be c; otherwise the step stops, or rotates the cell when `VACUUM_AXIS_POLICY` = rotate | Misoriented slabs | `skill/_common/opt/relax_common.py` (structure step of the VASP skills) |
| In-plane-only cell relaxation (IOPTCELL / OPTCELL in VASP; cell-filter mask for MACE); k<sub>z</sub> = 1 | Cell collapse along the vacuum axis | `skill/_common/opt/relax_common.py` (VASP skills); `skill/_common/mlff/mlff_relax.py` (MACE skills) |
| Check that the ZA branch is quadratic (ω ∝ q^p, 1.7 ≤ p ≤ 2.3) | A linearised ZA branch that passes the imaginary-mode gate but corrupts κ<sub>L</sub> | `skill/_common/za_2d.py`; `phonon-dft-cpu`, `phonon-mlff-*`, `kl-dft-cpu`, `kl-mlff-*`, `fit-fc-thermal` |
| Born–Huang and Huang constraints imposed in 2D force-constant fits | Force constants that violate rotational invariance | `skill/_common/fcfit/fc_fit_driver.py`; default in `fit-fc-thermal` (Pheasy); in `kl-dft-cpu` and `kl-mlff-*` only with `FIT_ENGINE` = pheasy or hiphive. Not imposed in `phonon-dft-cpu` (finite displacements; residual in-plane stress is checked first) or `phonon-mlff-*` (symfc; warns in 2D) |
| Thickness normalisation of κ<sub>L</sub>, σ and κ<sub>e</sub> (layer thickness from the atomic span plus van der Waals radii) | Quoting vacuum-diluted cell values as layer values | `skill/_common/thickness_2d.py`; `kl-dft-cpu`, `kl-mlff-*`, `fit-fc-thermal`, `phonon-lifetime`; `ke-dft-cpu` (`LAYER_THICKNESS`) |
| 2D electronic transport: vacuum-corrected dielectric and elastic inputs; opt-in 2D scattering kernels with sheet doping in cm⁻² | Sheet / bulk carrier-density unit mix-ups | `ke-dft-cpu` S8; opt-in S8.4 in `skill/ke-dft-cpu/step8.4_amset2d/` |
| zT on one cell basis (in-plane average of xx and yy) | Mixing sheet and bulk units in zT | `skill/zt-dft-cpu/step20_zt/zt_common.py` |

*Notes:* Paths are relative to the root of the AutoZT repository (version 1.2.0).
