# defect-dft-cpu：可配置本征缺陷候选与形成能分析

## 先明确适用范围

本技能生成孤立缺陷的有限候选集合，不保证覆盖所有重构、复合缺陷、间隙构型或电荷态。
候选数量不代表形成概率。形成能、化学势、温度、有限尺寸、自旋及弛豫收敛必须分别验证。
不再把测试通过、生成数量或历史目录名相同当作物理结论正确的证明。

## 超胞：默认不扩胞

`templates/step.conf` 默认 `SUPERCELL = 1 1 1`，倍数作用于输入 POSCAR，不隐式约化原胞。
S1在生成前打印输入原子数、倍数和最终原子数。已有项目的显式配置仍优先，不自动覆盖。

- Mg4C60 当前输入为 Mg8C120、128 原子：先用 `1 1 1` 初筛，不默认再扩成1152原子。
- 当前晶胞短周期平移约9.18 Å；一个Mg空位对应8个Mg中去掉1个。128原子并不证明稀释极限收敛。
- 对最终少数低能缺陷再做有限尺寸检查；小原胞材料仍应显式选择合适超胞。
- 历史9原子A2B2Te5的81原子设置需要显式 `SUPERCELL = 3 3 1`。

## 候选枚举及依赖

- `SYMMODE=auto` 使用spglib或pymatgen的真实空间群；无可靠后端报错，禁止旧元素/z近似用于生产去重。
- 占位轨道：每个轨道一个空位；反位将该轨道代表点替换成另一宿主元素。
- `DEFECT_TYPES=vacancy,antisite,pair,interstitial` 按需选择。
- `DEFECT_SPECIES=Mg` 表示缺陷涉及Mg，**包含两个方向的Mg/C反位**，不等于只做Mg空位和间隙。
- `ANTISITE_PAIRS=Mg-C,C-Mg` 指定替换对。`CATIONS/ANIONS`应人工核对；自动角色规则只是启发式。
- `pair`目前只给每对不同阳离子种类的一个交换示例，不是全部双缺陷/距离枚举。
- `N_INTERSTITIALS` 是原始网格种子预算；先挑种子再空间群去重，结果可少于该数，不为凑数回填附近网格点。
- 间隙使用正确周期最小距离；`site_count`记录晶胞内对称轨道大小。网格点的轨道仍是初始几何信息，
  最终间隙位置与多重度需在弛豫后复核，不能把采样点当已证明的稳定间隙。

### Mg4C60 当前输入的核对结果

输入 `/mnt/d/tf_data/hyl/Mg4C60_relax3/POSCAR` 在容差1e-5到1e-2 Å均为#15，
2个Mg轨道、30个C轨道。因此空位32、反位32。旧两个void种子严格对称等价，
不能按每元素两个不同间隙计数。修复后重新枚举实测 **66 = 32空位 + 32反位 + 2间隙**，
其中Mg_i、C_i各一个种子轨道（轨道大小4）。这是当前采样候选数，不是全部可能缺陷数。
旧68目录不得直接套用新manifest：去重后索引/候选位置可能变化，旧能量只能在验证结构映射后迁移。

## 工作流与计算口径

1. S0发现参考相：`REFERENCES_DIR/convex_hull_references/<phase>/POSCAR`；单元素每原子、多元素每式量。
2. S1体相按显式重复倍数生成，S2优先使用其CONTCAR生成缺陷并弛豫。
3. S3仅处理非零电荷态；中性态复用S2，不重建q0作业。中性专用流程通过显式空扇出清单完成。
4. S4先汇总，成功完成参考/形成能分析后才写最终完成标记；失败非零退出，不能只凭部分汇总判完成。

`SOC=0`选vasp_std，`SOC=1`选vasp_ncl。ENCUT、PAW、泛函和k网格需要一致且收敛；
势对齐不能修复使用不同计算参数的错误。参考相缓存必须核对计算口径，不能盲目复用历史文件。

### 电荷与统计

- 金属项目显式 `IS_METAL=1`，使用中性缺陷（`QMIN=QMAX=0`），分析拒绝金属非零q，避免不明确的电子库零点/修正约定。
- 半导体 `CHARGE_MODE=window` 只覆盖所选有限区间，**不保证包含所有稳定电荷态**。
- 默认 `CHARGED_GEOMETRY=relax`、`CHARGED_NSW=60`、`CHARGED_EDIFFG=-0.02`；检查每个带电态实际弛豫收敛。
  `CHARGED_GEOMETRY=vertical` 仅为显式选项，输出带垂直能量警告，不当作热力学稳定态。
- 同一缺陷各电荷态共享一个含无缺陷态的配分函数，不再分别用logistic相加超过位点数。
- 生长冻结使用唯一目录ID，避免同名不同位点相互覆盖；报告与求根共用浓度模型。
- 类型汇总提供 `by_name`、`by_type`，但它是独立缺陷近似：不同缺陷家族竞争同一子晶格、
  强相互作用、重构及高浓度情形仍需专门模型，不能把数值饱和护栏当作完整相平衡。
- 缺manifest、成分、能量或化学势应报错，不以零值补齐后给排名。

## 化学势与稳定性

凸包支持合法单点窗口及单元素，单元素同样要检查全部竞争相约束。
`energy_above_hull`单位eV/atom，非负；=0仅表示相对于已给参考集处在计算凸包上，
不证明参考集完整、有限温稳定或可合成。>0说明目标相对当前参考集亚稳。
空窗口不得静默改用元素窗口或旧化学势冒充成功；亚稳相分析需单独说明外加化学势及适用条件。

## 测试与使用纪律

使用装有spglib的环境运行 `python selftest.py --strict`。无依赖环境的非严格测试可跳过相关积分测试，
不能据此宣称生产枚举可运行。回归覆盖：合法单点凸包、斜晶胞MIC、空间群去重、互斥占位、极端能量。
另用真实Mg4C60验证候选数，并用隔离输出检验S3中性零作业及S4失败不产生成功标记。

生成/分析测试不等于运行过VASP。测试用假POTCAR或合成能量的目录不能用于生产或物理结论。
正式提交、重跑、清理和迁移旧结果仍需用户授权；不要覆盖已有受保护结果。
